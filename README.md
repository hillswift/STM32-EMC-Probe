# STM32-EMC-Probe
# 基于STM32的简易EMC近场电场探测仪
功能演示视频： [B站 - EMC简易近场探测仪](https://www.bilibili.com/video/BV1zrYa6gEKQ/)
一款便携式近场EMI电场探测设备，用于电路板辐射干扰源的定位排查。采用两级程控增益放大、有源峰值检波、STM32数字采集与处理，支持两档量程切换、峰值保持、饱和提示和蜂鸣器变频提示。
## 功能特性
- 两档程控增益：×20 / ×200，模拟开关切换
- 有源峰值检波，提取交流信号峰值
- 开机自动零点校准 + 手动校准
- 滑动窗口数字滤波，读数平稳
- 峰值保持模式，方便扫板定位干扰源
- 输出饱和检测与提示
- 蜂鸣器随信号强度变频鸣叫
- 0.96寸OLED显示，信息直观
- 
## 硬件架构
### 核心器件
- 主控：STM32F103C8T6
- 运放：SGM8052XS/TR（双路轨到轨低噪声运放）
- 模拟开关：SN74LVC1G3157DBVR
- 检波二极管：BAT54S 肖特基二极管
- 显示：0.96寸 96×32 OLED（SPI接口）
### 信号链路
天线感应 → 第一级固定 20 倍放大 → 模拟开关切换第二级增益 → 有源峰值检波 → STM32 ADC 采集 → 数字处理 → OLED 显示 + 蜂鸣器
### 硬件设计亮点
- 单电源3.3V供电，1.65V中点偏置，保证交流信号完整放大
- 磁珠+电容实现数模电源分离，抑制数字噪声串扰
- 模拟/数字分区布局，单点接地架构
- 每芯片电源引脚就近去耦

## 使用说明
1.  上电自动校准零点，等待稳定
2.  PB1按键切换增益档位（×20大量程 / ×200高灵敏度）
3.  PB2按键手动重新校准零点
4.  PB10按键切换峰值保持模式
5.  屏幕右侧 `SAT` 亮起表示输出饱和，请切低增益档
6.  蜂鸣器鸣叫越急促表示信号越强

## 问题与解决
- 问题：LDO 输出电压异常偏高，实测输出 4.02V，远高于标称 3.3V
- 原因：HR1117-3.3 线性稳压器的 GND 引脚未可靠焊接到地层，形成浮地状态，导致内部基准偏移，输出电压失控。
- 解决：刮开 PCB 对应位置的阻焊层，露出地铜皮，补焊 LDO 地引脚与系统地的连接，输出电压恢复至 3.3V 正常范围。
- 问题：运放静态输出工作点异常，交流信号变化被直流基底淹没，检测无明显反应
- 原因：单电源供电下，两级运放的负反馈网络下端直接接地，输入端的 1.65V 直流偏置被运放增益放大，输出静态电压严重偏离电源中点，小幅交流信号被大直流基底掩盖，无法正常识别。
- 解决：将两级运放的负反馈网络下端统一改接 1.65V 偏置基准，使运放输入、输出端直流电位保持一致，让交流信号全周期工作在线性放大区。
- 问题：高增益档输入信号较强时，输出出现削波失真，数值反向变小
- 原因：输入信号幅值超出当前增益下的线性范围，运放输出进入饱和区，顶到电源轨，峰值检波后电压不再随输入增大，换算后的等效输入值反而偏小。
- 解决：增加输出饱和检测功能，设定 2.4V 饱和阈值，屏幕显示 SAT 标识提示用户切换低增益档，保证测量始终在线性区间。
- 问题：ADC 原始读数跳动明显，数值不稳。
- 原因：空间电磁干扰、ADC 量化噪声共同导致采样值随机波动。
- 解决：软件加入两级滤波，先做单次 20 点采样平均抑制随机噪声，再通过 16 阶滑动窗口滤波进一步平滑输出，兼顾读数稳定性与响应速度。
